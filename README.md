# 🐾 2027 山貓追火車 GOGOGO — 組隊媒合系統

網站：<https://jasonzhi731.github.io/wildcat-train-relay/>

2027 追火車（新北市鐵道馬拉松接力賽）跑友自發的組隊媒合網站。
**非官方報名網站**：正式報名、繳費仍要由各隊隊長到官方網站完成。

- 網頁：放在 GitHub Pages（免費）
- 資料：存在你自己的 Google Sheet（透過 Google Apps Script 讀寫）
- 手機優先設計（大多數人會從 LINE 點開）

---

## 功能

| 給誰 | 可以做什麼 |
|---|---|
| 第一次來的人 | 填姓名、手機、生日（月日 4 碼）、LINE ID、性別 → 報名完成後顯示 LINE 群組按鈕與 QR code |
| 已報名的人 | 用 **手機＋生日 4 碼** 登入，查看所有隊伍、待安排名單、修改自己的資料 |
| 想自己組隊 | 建立隊伍（當隊長）→ 把**邀請連結**傳給朋友，朋友點連結報名就直接入隊 |
| 想加入別人 | 在「所有隊伍」申請加入，隊長同意後入隊（隊長也可設成「開放直接加入」） |
| 人數不夠的小隊 | 隊長按「**整隊申請併入**」別隊，對方同意後整隊一起移過去，朋友不會被拆散 |
| 還沒想法 | 什麼都不用做，留在「待安排」；隊長可以邀請你，管理員也可以幫忙分隊 |
| 管理員（你） | 網址後面加 `#admin`：搬人、用待安排的人建隊、設定隊長、重設生日碼、刪除資料、複製各隊名單 |

### 隊伍規則（2026 年官方規定，可在「設定」工作表調整）
- 每隊 7 位正式隊員＋2 位候補，上限 9 人；一人只能在一隊。
- 第一棒必須是女性：隊伍卡片會顯示女性人數，沒有女生會提醒。
- 同時「待回覆」的申請最多 3 個；被任一隊接受後，其他申請自動失效。
- 隊長離開時，隊長自動交給最早入隊的人；最後一人離開，隊伍自動解散。
- 隊伍額滿時，其他人對這隊的申請自動失效。

### 第二階段（先寫好、預設關閉）
官方 2027 資訊出來後，到 Google Sheet 的「設定」工作表勾選 **開放第二階段**，網頁就會出現：
- 是否滿 18 歲、想跑的棒次、可跑距離、配速、偏好組別、是否願意當候補、是否願意代表報名、跑衣尺寸
- 隊伍頁的 **棒次表**，隊長可以分配第 1～7 棒與候補（第 1 棒只能選女性）
- 提醒：還沒分配的棒次、未滿 18 歲需要家長同意書、誰還沒填資料

> 欄位與選項寫在 `apps-script/Code.gs` 最上面的 `LEGS`（棒次與距離）和 `PHASE2_FIELDS`（第二階段欄位）。
> 2027 年簡章公布後，請把新規定告訴 Claude，或自己修改這兩段。

## 一、先在自己電腦試用（不需要 Google 帳號）

1. 在檔案總管打開 `C:\train-relay`，雙擊 **`本機預覽.cmd`**。
2. 瀏覽器開啟 <http://localhost:8080/>（沒有自動開啟就自己輸入）。
3. 畫面上方會顯示「🧪 本機模擬模式」，按 **產生示範資料** 會建立 12 位示範成員與 3 個隊伍：
   - 示範帳號：電話 `0900000001`～`0900000012`，生日都是 `0101`
   - 管理頁：<http://localhost:8080/#admin>，密碼 `admin1234`（只有本機模擬模式用這個密碼）
4. 後端自動測試：<http://localhost:8080/tests/backend.html>，最上面顯示「PASS：通過 32 / 32」就是全部通過。
5. 關閉 `本機預覽.cmd` 開出來的黑色視窗就會停止。

> 模擬資料只存在這台電腦的瀏覽器裡，不會送到任何地方。按「清除模擬資料」可以重來。

## 二、正式上線（大約 20 分鐘）

### 步驟 1：建立 Google Sheet
1. 到 <https://sheets.google.com> 建立一個新的空白試算表，命名例如「追火車組隊」。
2. **這個試算表不要分享給別人**（裡面有大家的手機號碼）。

### 步驟 2：貼上後端程式
1. 在試算表選單按 **擴充功能 → Apps Script**。
2. 把左邊 `程式碼.gs` 裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的**全部內容**，按 💾 儲存。
3. （選用）左邊 ⚙️「專案設定」→ 時區選「(GMT+08:00) 台北」。

### 步驟 3：初始化
1. 上方函式下拉選單選 **`setup`**，按 **▶ 執行**。
2. 第一次會要求授權：選你的 Google 帳號 →
   出現「Google 尚未驗證這個應用程式」時按 **進階 → 前往「（專案名稱）」（不安全）** → **允許**。
   （這是你自己寫的程式，只是沒有送 Google 審查，所以會出現這個警告。）
3. 回到試算表，會多出 **設定、成員、隊伍、申請、紀錄** 五個工作表。原本的「工作表1」可以刪除。

### 步驟 4：設定管理頁密碼
1. Apps Script 左邊 ⚙️ **專案設定** → 拉到最下面 **指令碼屬性** → **新增指令碼屬性**。
2. 屬性填 `ADMIN_PASSWORD`，值填你自己想的密碼（**至少 8 碼**，不要跟其他帳號共用）→ 儲存。
3. 不要動 `TOKEN_SECRET`（系統自動產生的登入金鑰）。

### 步驟 5：部署成網頁應用程式
1. 右上角 **部署 → 新增部署作業**。
2. 左邊齒輪「選取類型」選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（不是「擁有 Google 帳戶的所有人」）
4. 按 **部署**，複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
5. 用瀏覽器打開這個網址，看到 `"ok":true` 與「API 運作中」就成功了。

### 步驟 6：把網址填進網頁
打開 `js/config.js`，把網址貼在 `API_URL` 的引號裡：
```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/……/exec',
};
```

### 步驟 7：放上 GitHub Pages
1. 登入 <https://github.com>，右上角 **＋ → New repository**。
   名稱例如 `train-relay`，選 **Public**（免費帳號的 GitHub Pages 需要公開；程式裡沒有任何密碼）→ Create repository。
2. 在新 repo 頁面按 **uploading an existing file**，把 `C:\train-relay` 裡的**所有檔案與資料夾**拖進去 → **Commit changes**。
   （熟悉的話也可以用 GitHub Desktop 或 git。）
3. repo 的 **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)** → Save。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/train-relay/`。

### 步驟 8：設定 LINE 群組連結
1. 在 LINE 群組右上角選單 → **邀請** → **複製連結**（`https://line.me/ti/g/……`）。
2. 貼到 Google Sheet「設定」工作表的 **LINE群組連結** 那一列的「值」欄。
   - 只有已報名的人才看得到這個連結（所以不要寫在 `config.js`，那個檔案所有人都看得到）。
   - 網頁會自動產生 QR code 給用電腦開的人掃。

### 步驟 9：自己測一次
用手機打開網站 → 第一次報名 → 建一個測試隊伍 → 到 Google Sheet 看「成員」「隊伍」有沒有資料 → 用管理頁刪掉測試資料。

## 三、之後的操作

| 想做的事 | 怎麼做 |
|---|---|
| 修改公告、暫停報名 | 「設定」工作表：改「公告」、取消勾選「開放註冊」（立即生效，不用重新部署） |
| 開放第二階段 | 「設定」勾選 **開放第二階段** |
| 官方開報前凍結隊伍 | 「設定」勾選 **鎖定隊伍**：大家不能再自行換隊，管理頁仍可調整 |
| 拿名單去正式報名 | 管理頁每隊下方 **📋 複製名單** |
| 有人忘記生日碼 | 在 LINE 確認是本人 → 管理頁 **重設生日碼** |
| 修改了 `Code.gs` | 貼上新程式並儲存 → **部署 → 管理部署作業** → 鉛筆圖示 → 版本選 **新版本** → 部署。⚠️ 不要按「新增部署作業」，那樣網址會變 |
| 修改了網頁檔案 | 這個資料夾已經用 git 連到 GitHub repo `wildcat-train-relay`：請 Claude 修改後直接推送（push），1～2 分鐘後網站自動更新。每次修改都要把 `index.html` 裡的 `?v=` 版本號加一，避免手機用舊的快取 |
| 活動結束 | 依告知事項的保存期限，刪除「成員」「申請」「紀錄」工作表的資料 |

> 請用管理頁調整隊伍，**不要直接改「成員」工作表的「隊伍編號」「角色」欄**，否則隊長、人數可能對不起來。
> 在工作表最右邊自己加欄位（例如「繳費狀態」）沒問題，程式不會動到。

## 四、隱私與安全

| 資料 | 誰看得到 |
|---|---|
| 姓名、性別、所屬隊伍、希望同組 | 已報名（登入）的人 |
| 第二階段的棒次偏好、距離、配速、組別、是否當候補 | 已報名的人 |
| LINE ID、是否滿 18 歲、跑衣尺寸 | 同隊隊友 |
| 手機號碼 | 只有管理員（管理頁、Google Sheet） |
| 生日月日 | 沒有人：只存不可還原的雜湊值 |

- 生日只有 366 種可能，所以同一支電話 **連續錯 5 次會暫停登入 15 分鐘**；管理頁密碼也一樣。
- 所有規則都在後端（Apps Script）檢查，就算有人直接呼叫 API 也無法越權。
- 輸入的文字會去掉開頭的 `= + - @`，避免被 Google Sheet 當成公式。
- 個資告知事項在報名表上，必須勾選同意才能報名。

## 五、已知限制

- **不會自動通知**：有人申請時，隊長要登入才看得到（LINE Notify 已在 2025 年停止服務）。可以在 LINE 群組提醒隊長。
- Google Apps Script 每次操作約需 1～3 秒。
- Apps Script 同時處理的請求有上限（約 30 個）；報名開放時如果大家同時湧入，少數人可能看到「目前使用的人比較多」，稍後再試即可。
- 沒有防機器人驗證，理論上可能被灌假資料；發現時可以在管理頁刪除，或暫時取消「開放註冊」。

## 六、常見問題

- **網頁顯示「網站還沒設定後端網址」**：`js/config.js` 的 `API_URL` 沒填，或上傳的是舊檔案。
- **顯示「伺服器回應格式不正確」**：部署時「誰可以存取」不是「所有人」，請重新部署。
- **改了 Code.gs 但網站沒變**：要用「管理部署作業 → 新版本」重新部署。
- **管理頁說沒有設定密碼**：步驟 4 的 `ADMIN_PASSWORD` 沒設定，或少於 8 碼。
